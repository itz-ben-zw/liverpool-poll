# Archicad Agent Bridge VS Code Extension

This extension contributes:

- `@archicad` chat participant
- `#createHousePlan` language model tool
- `Archicad Agent Bridge: Create House Plan From Prompt` command

It expects Archicad 28 to be running with the `AgentBridge` add-on loaded.

## Develop

```powershell
npm install
npm run compile
```

Then press `F5` in VS Code and use `@archicad` in the Extension Development Host chat.
